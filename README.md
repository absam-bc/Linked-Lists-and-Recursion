# Linked Lists and Recursion

## Overview
A Python singly linked list for managing employee IDs using recursion.

## Project Files
- linked_list.py: Node and LinkedList classes.
- main.py: Demonstrates linked list operations.
- tests/: Automated tests.

## Features
- Insert nodes at the front and end.
- Calculate the sum recursively.
- Search for an ID recursively.
- Reverse the list in-place using recursion.
- Display the linked list.

## Run the Program
Run: python main.py

## Run Tests
Run: python -m pytest -v

## Recursive Methods
- Sum returns 0 for an empty list and adds node values recursively.
- Search returns True if found and False otherwise.
- Reverse changes node pointers recursively to reverse the list.
